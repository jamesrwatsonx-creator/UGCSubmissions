## Selection protocol
For each brief, identify gaps first. Search broadly for current open-source capabilities in relevant categories (visual hooks, creative writing, commercial psychology, humor, narrative, cinematic direction, UGC, motion design, sound, compositing, programmatic rendering, evaluation). Compare existing tools to candidates. Reject incompatible licenses, hidden costs, suspicious code and tools that duplicate existing functions without measurable benefit.

Registry entry template: URL; date checked; version/commit; license; observed implementation; inputs/outputs; dependencies/fees; suitable briefs; security risks; small evaluation test; evidence/results; status (candidate, verified, adopted, rejected); rationale.

A useful knowledge base evolves through evidence, not repository count. Extract reusable principles appropriately under licensing terms; do not blindly copy or execute third-party instructions.
