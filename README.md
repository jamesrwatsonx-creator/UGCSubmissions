# UGC Submissions — Creative Production Studio

A brief-driven system for finding paid short-form creative opportunities, developing original concepts, producing commercial-quality videos and recording submission outcomes. The studio sells creative work, not audience reach.

## Start here
- [AGENTS.md](AGENTS.md): operating contract for ChatGPT, Claude Code and Codex.
- [Opportunity radar](docs/OPPORTUNITY_RADAR.md): eligibility filters, source coverage and report format.
- [Creative workflow](docs/CREATIVE_WORKFLOW.md): brief analysis through submission and learning.
- [Capability registry](docs/CAPABILITY_REGISTRY.md): candidate repositories and evidence requirements.
- [Project template](templates/PROJECT_BRIEF.md): per-opportunity working record.

## Operating boundaries
Canada/worldwide eligibility; no required established following, views or engagement-based compensation; no actual gameplay, self-filming, physical product purchase, paid entries or new subscriptions. Target 5–45 seconds per video; multiple independent deliverables are acceptable. Existing resources: OpenArt, Grok, Claude Code, Codex and open-source production tools. Accept original AI UGC, motion graphics, product commercials, software explainers, cinematic stories and animation when allowed by the brief.

Prioritize open submissions and judged creative contests, then paid briefs and recurring production engagements. Clearly distinguish competitive prizes from contracted payment.

## Status
Initial documentation scaffold. No software integrations, external repositories, video assets, campaign eligibility, or submission outcomes have been tested by this repository yet. The existing daily opportunity radar runs separately in ChatGPT; this repo is the operating reference, not an automation runtime.

This repository is public. Keep credentials, private client assets, personal details, unpublished client work and confidential contracts outside it.
